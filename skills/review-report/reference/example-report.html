Overview

Where this change sits

Greeter builds the greeting text from whatever string the caller passes. This change puts a Name type between the caller and Greeter.

Green is new, yellow is changed; the caller is untouched.

Why this change

Passing a raw String let callers send empty or malformed names. Bugs showed up far from the call site.

What changes

Introduce a Name record and make Greeter.greet accept only that type. Callers must construct a Name, so validation happens once, at the boundary.

How to read this report

Top to bottom: the new type first, then the call site that adopts it, then the class it replaces. Docs and the migration table close the report.

New terms

Name
New value object wrapping a person's name, so callers cannot pass an arbitrary string.
